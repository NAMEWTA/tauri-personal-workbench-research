# Archives

**档案**：隶属于一个档案类型的用户内容记录，由标题、摘要、正文和按字段定义校验的动态字段值组成。面向用户语义时避免使用“generic entity”。

**档案类型**：用户管理的 Schema 记录，拥有名称、图标、颜色和有序字段定义；个人、企业、事件只是可编辑种子模板。它不是代码枚举或硬编码类别。

**字段定义**：档案类型拥有的动态字段合同，规定 key、值类型、分组、必填、选项、默认值、敏感标记和排序。它不是固定数据库列或无约束自由 JSON。

**敏感字段**：由字段定义标记并在 UI 默认遮罩的显示语义；值仍以明文进入 SQLite、搜索索引与未加密备份。它不等同于加密字段或权限字段。

**事件档案**：Archive context 中名为“事件”的种子档案类型，不是可排程实体。避免称为“日历事件”或 `CalendarEvent`。

**档案关系**：从 source 档案指向 target 档案的有向、带类型和备注的关系；反向或无向语义不会自动成立。

**托管附件**：由 workbenchd 复制进工作区、记录相对路径和 SHA-256、当前归属于档案的文件副本。它不是原文件链接、外部路径附件或任务附件。

**档案活动**：`change_log` 对单个档案变更的只读历史投影，不是事件溯源事实源，也不是全实体活动流。
